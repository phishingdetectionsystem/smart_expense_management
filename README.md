
# Smart Expense Management System

## Project Description

Smart Expense Management is a web application
used to track and manage daily expenses.

It is developed using Python Flask, HTML, CSS,
JavaScript and SQLite.

## Features

1. Expense Dashboard
2. Add Expenses
3. View Transactions
4. Delete Expenses
5. Search Expenses
6. Monthly Expense Summary
7. Category-wise Analytics
8. SQLite Database Storage
9. Responsive Design

## Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- SQLite

## Installation

1. Open the project in VS Code.
2. Create a virtual environment:

   python -m venv venv

3. Activate it:

   venv\Scripts\activate

4. Install dependencies:

   pip install -r requirements.txt

5. Run the project:

   python app.py

6. Open the browser:

   http://127.0.0.1:5000

## Database

The expenses.db database is created automatically
when the Flask application starts.
